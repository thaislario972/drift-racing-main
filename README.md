# Drift Racing Game 🚗💨

A small 2D drift game developed with React, TypeScript and PixiJS.

Originally created for internal use within my company, the goal was simple: create a fun drift experience where players can choose different cars, drive on multiple tracks and try to master drifting mechanics.

## Features

* Multiple playable cars
* Different circuits / maps
* Keyboard controls
* Drift mechanics
* Car selection system
* Circuit selection system
* Responsive game interface

## Controls

↑ → Accelerate
↓ → Reverse
← / → Turn
Space → Handbrake

## Tech Stack

* React
* TypeScript
* Vite
* PixiJS
* P2 Physics

## Why this project?

This project was created mainly out of curiosity and passion for both automotive culture and interactive experiences.

Beyond simply building a game, the objective was also to explore:

* Game interaction design
* User experience in interactive systems
* Physics simulation
* Front-end architecture for real-time interactions
